## 安装

1. 打开你的 AI 助手的「技能 / 插件 / Skills」入口。
2. 点「导入 / Import」，选中 `技能包/` 里的**某一个技能文件夹**（例如 `zpsz-zhengguan-ge`）。
3. 导入后启用即可。每个技能是一个独立文件夹，里面只有一个 `SKILL.md`，一次导入一个文件夹。

> 建议按要问的方向只开启对应 1–3 个技能，避免互相抢触发。

## 使用示例

给助手一个八字排盘（年柱 月柱 日柱 时柱），然后问对应领域的问题：
