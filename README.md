# 子平真诠技能包 · 五模型蒸馏融合版 V1.1

**五个 AI 模型各蒸一版《子平真诠评注》，取五家之长融合成一套**：8 个格局派八字分析技能（七格局 + 行运总纲），555 条断法规则全部带原文溯源，16 组沈孝瞻原文与徐乐吾评注的冲突逐条裁决，140 条抽验 100% 命中原文、34 题盲测全对。

这不是简单的"五选一"，而是一次真正的蒸馏产物工程：五个模型各自跑完整套「命学真典」蒸馏流程后，横向评测、交叉验证、分层裁决、合并重造。

## 五个版本各强在哪

| 版本 | 独门绝活 | 融合时取了什么 |
|------|----------|----------------|
| **千问版** | 候选库最厚——555 条规则 + 315 个命例，每条带模型路径/触发条件/失效条件/原文摘录/沈徐双署名 | 全量候选库作基座 |
| **V4-flsh 版** | 流程最严谨——11 组沈徐冲突逐条裁决，唯一把「论行运」独立成技能 | 行运总纲技能 + 冲突裁决体系 |
| **Kimi 版** | 操作手册式写法——五类配置分型（兼用财印/单用财/佩印/带伤食/带煞）清晰好查 | 配置分型速查表，并入全部格局技能 |
| **ds4-p 版** | 八格拆分最细——食神/伤官各自成章，食伤体性之辨最全 | 食神伤官五维对照速查 |
| **GLM5.3 Flash 版** | 文案与边界意识最好——"时辰不准的盘怎么办""别家用神概念错位""书内样本全是名人贵格反推" | 三条边界声明 + 「月令如城，本气是知府、余气是同知」记忆锚点 |

## 融合后强在哪

1. **8 个技能，比任何单版多一个**：七个格局技能（正官/七杀/财/印绶/伤官食神/禄刃/杂格）+ 行运总纲 ziping-xingyun（取运同法/成格变格/逢运透清/冲法缓急/九格取运速查表）——单版要么没有行运技能，要么没有它的速查表与格局技能双向索引。
2. **16 组冲突裁决，两包基准相反也能合**：千问版以沈原文为主、V4 版以评注优先，融合版改用**分层裁决政策**——通则以沈为主、沈的技术性错误（如"食神合煞"实为伤官之误）采徐注修正、个案分歧双说并存、徐注内部矛盾取后出细则。每一条裁决带理由，见 `候选/冲突记录-融合版.md`。
3. **三重质检背书**：①40+100 条互补抽样，原文摘录 **140/140 全命中**、块号零误差；②555 条规则五字段完整性机检全过；③独立盲测 34/34 全对——含"印格走什么运归印格技能而非行运技能"这类最容易抢答出错的边界题。
4. **顺手修复了基座缺陷**：原千问版的模型画布 bazi-index 只有空标题、书专属模型树一直没接上，融合时用骨架的 L4-L8 树重组，555 条规则路径节点 14/14 全命中。
5. **全套即装格式**：每个技能一个 `.skill` 文件，导入即用；技能内 desc 写明互相依赖与让渡关系（七杀当令食神制杀归七杀格，伤官格不抢答）。

## 使用方式

给 AI 助手一个八字排盘（四柱天干地支）+ 性别，直接问：

- 「甲申、壬申、乙巳、戊寅，这个八字能做官吗」→ 正官格技能
- 「月令七杀，食神透出制杀，怎么断」→ 七杀格技能
- 「格局已定，下一步壬辰大运好不好」→ 行运总纲技能

内置取格判定，无需先跑"取格技能"。建议一次开 2-3 个格局技能 + 行运总纲。

## 安装

两种方式任选：

- 直接导入 `技能包/` 目录下任意 `xxx.skill` 文件（推荐，QwenWork 等助手即点即装）
- 或把技能文件夹整个放入技能目录（如 `~/.qwenworkcn/skills/` 或 `~/.workbuddy/skills/`）
