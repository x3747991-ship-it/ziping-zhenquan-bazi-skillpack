# 论行运（大运流年总纲）

## 什么时候用它

用户已经拿到一个八字，想知道"大运走得好不好""这一步运是翻身还是走背字""某十年吉凶如何"。本技能是**大运流年总纲**，只解决"拿到已定格的八字，怎么一步步断它的大运吉凶"。

**前置依赖（必须先用别技能完成）**：本技能不负责定格局。必须先调用格局技能（ziping-zhengguan-ge / ziping-cai-ge / ziping-yin-ge / ziping-shangguan-ge / ziping-sha-ge / ziping-lu-ren-ge / ziping-za-ge）把**格局与用神、相神**定出来，再套本技能。没定格局就直接查"各格取运速查表"会得出空结论。

## 涉及的模型节点

- L1 四柱 > 藏干透出 / 透清
- L2 十神 > 组合义（官煞并见 / 财印相战等）
- L3 冲合刑害 > 六冲 / 会合解冲 / 因会而动
- L4 技法体系 > 论行运（元规则）> 论行运总则 / 行运成格变格 / 喜忌干支有别 / 支中喜忌逢运透清
- L4 技法体系 > 八正格 / 杂格（九格）取运
- L7 大运流年体系 > 取运总纲 / 通用断法
- L8 断事 > 大运流年

## 核心判断

大运吉凶不在干支字面，而在干支与命中喜用的**配合**：助喜用为吉、逆喜用为凶；运更能**成格变格**，其力比单纯喜忌祸福更重。干主动、支主静，一字之喜忌须十年并论、以方为重，绝不可断章取义。

## 断法步骤

1. 确认已定格局、用神、相神与命中喜忌（输入前置依赖）[L4 技法体系 > 论用神]
2. 取运与看命同法：以运干配八字喜忌，运以方为重、十年并论，不以一字断 [L7 取运总纲]
3. 辨行干不行支 / 行支不行干、干同类不两行 / 支同类不两行，定运中哪一字真正发力 [L7 行干不行支等]
4. 查冲：分缓急（冲提纲 / 喜用为重）、分轻重（运喜冲忌轻、运忌冲喜重），会合解冲则不冲，留意一冲引两冲 [L3 六冲 / 会合]
5. 查支中喜忌逢运透清、命与运二支会局作清（静而待用者正得其用）[L7 透清]
6. 查行运成格变格（较喜忌尤重），兼看本命有无救应（逢成不喜 / 逢变不忌）[L7 成格变格]
7. 按所定格局查"各格取运速查表"定喜行 / 忌行 [L7 各格取运]
8. 综合得出"此步运吉凶"结论，回头用参考命例校验 [L8 大运流年]

## 判断标准

断对了会看到：运助喜用则升迁发财、运逆喜用则困顿；成格变格之时命运起伏明显（如姚文敷寅运顿清）；透清发动之年应事清晰（如姚君巳运得意、卯运不禄）；冲分缓急轻重与实际遭际合拍。

断错了会看到：只按干支字面断吉凶、忽略"运以方为重十年并论"而断章取义一字；把支静待用误判为已发动；未定格局就硬套九格速查表得出空结论；不察本命救应而误判"逢成必喜 / 逢变必忌"。

## 什么时候不该用它

- **必须先定格局**：未用格局技能定出用神相神前，本技能无法使用；否则九格速查表与成格变格判断全无依托。
- **时辰不准的盘**：时柱定不了时，透清、成格变格（时支藏干逢运引出）两套判断直接失效，结论只能标"待定时辰复核"。
- **时代与流派局限**：本书以"官贵"为唯一价值本位（大贵 / 孤官无辅 / 七品百里），对现代商业成功、专业技术、自由职业、企业主等富格缺独立标尺，断"翻身"须重新标定。
- **用户用别家"用神"概念**：本书用神专指月令定格之神，与《滴天髓》扶抑体系同名不同义；对方拿别家"喜用"直接套问时，先说清定义再动盘。
- **女命 / 健康 / 灾祸无系统断法**：本书几乎不涉女命，健康灾祸仅零星涉及，直接套用得空结论。
- **从格 / 化格 / 专旺失效**：月令取用法对气势偏旺之局失灵，真假从化判定本书无定法（舍侄某化神还原即破）。
- **同时辰生人反例**：同年同月同日同时生者命运各异，全书不处理此反例。
- **不可只问当年流年**：本技能断大运（十年），单问某年吉凶应结合流年太岁另论，不单靠本技能。
